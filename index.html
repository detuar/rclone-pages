Application Purpose & Architecture

Created to provide dedicated Google OAuth 2.0 Client ID credentials for personal rclone operations, avoiding shared public rate limits while maintaining complete data sovereignty.

100% Local Authentication

When you authorize access via Google's OAuth 2.0 consent screen, the authorization code is returned directly to 127.0.0.1 (your local device). Your OAuth refresh and access tokens never leave your computer except to authenticate directly with Google.

Automated Backups & Sync

Enables reliable command-line file synchronization, encrypted rclone crypt archives, integrity verification (checksums), and virtual filesystem mounting between your local storage and your Google Drive account.

Strict Zero-Data Collection

This project operates no backend database, no analytics tracker, no telemetry pipeline, and no proxy servers. We cannot see, read, log, or access your Google account profile, files, or credentials.

Google API Scopes & Justification

Depending on how you configure your rclone remote, the application requests one of the following Google Drive API scopes solely to perform the file operations you explicitly run on your machine:

OAuth 2.0 Scope URI rclone Access Level Why This Scope Is Requested
https://www.googleapis.com/auth/drive Full Access (drive) Allows rclone to list, upload, download, move, rename, and synchronize files and folders across your Google Drive as instructed by your local CLI commands.
https://www.googleapis.com/auth/drive.file Per-File Access (drive.file) Restricts rclone so it can only view and manage files and folders that were specifically created or uploaded using this OAuth client.
https://www.googleapis.com/auth/drive.readonly Read-Only (drive.readonly) Allows rclone to download and verify files from your Google Drive for local backup without permission to modify or delete cloud files.
https://www.googleapis.com/auth/drive.metadata.readonly Metadata Only Used when inspecting file listings, directory trees, sizes, and hashes without downloading actual file contents.
https://www.googleapis.com/auth/drive.appfolder App Data Folder Grants access exclusively to a hidden application configuration folder inside Google Drive without touching personal Drive files.
